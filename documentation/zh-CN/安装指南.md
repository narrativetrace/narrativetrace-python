# 安装

NarrativeTrace 面向 Python ≥ 3.12,以一组软件包的形式发布:一个无依赖的核心包,加上可选的集成包。

```bash
uv add narrativetrace                 # 仅核心包
uv add narrativetrace-pytest          # pytest 插件(附带核心包 + diagrams)
uv add narrativetrace-diagrams        # Mermaid / PlantUML 渲染器
uv add narrativetrace-otel            # OpenTelemetry 桥接(opentelemetry-api)
uv add narrativetrace-asgi            # Starlette/FastAPI 中间件
uv add narrativetrace-clarity         # 命名清晰度引擎 + CLI 门禁
uv add narrativetrace-structlog       # structlog 处理器
```

`pip install narrativetrace` 效果相同。只需添加你实际会用到的集成包——核心包不携带任何第三方依赖。

PyPI 发布尚未完成 —— 在这些包上架索引之前,请按下文从本仓库的检出目录安装。

## 从本仓库安装(工作区模式)

```bash
uv sync --all-packages     # 以可编辑模式安装工作区中的所有软件包
uv run poe check           # 运行完整的质量门禁
```
