# Equivalent-mutant ledger for narrativetrace-tooling, read by `poe mutate-tooling-gate`
# (scripts/mutation_gate.py, invoked with the "narrativetrace-tooling" argument).
#
# Same format as mutation/equivalents.txt: one line per mutant, the mutmut mutant id (as printed
# by `mutmut results` from packages/narrativetrace-tooling), a tab, then a one-line reason a human
# can review. A mutant listed here is excluded from the gate's denominator — it can never be killed
# because the mutated code is behaviourally identical to the original, not because the test suite
# has a gap. Every entry must be re-verified (`mutmut show <id>`, run from
# packages/narrativetrace-tooling) before being trusted; do not add an entry just because a mutant
# survives.
#

# `doctor/checks/*` — code this milestone moved rather than wrote, whose survivors were previously
# counted against the `narrativetrace` package's own score. Add entries here only after triage
