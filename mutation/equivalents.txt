# Equivalent-mutant ledger, read by `poe mutate-gate` (scripts/mutation_gate.py).
#
# One line per mutant: the mutmut mutant id (as printed by `mutmut results`),
# a tab, then a one-line reason a human can review. A mutant listed here is
# excluded from the gate's denominator — it can never be killed because the
# mutated code is behaviourally identical to the original, not because the
# test suite has a gap. Every entry must be re-verified (`mutmut show <id>`)
# before being trusted; do not add an entry just because a mutant survives.
#
# Provenance: the private backlog ("uv run poe mutate is broken") documented
# these 15 as equivalent when the mutation harness was repaired on
# 2026-08-31. Moved here verbatim on 2026-09-01 so the gate can read them
# without parsing prose.
